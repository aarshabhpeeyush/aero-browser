# Desktop GIFs

Made by **rayytor**: https://github.com/rayytor/desktop_gifs (version 0.1.8).
It is free software under the GNU General Public License v3.0 (see `LICENSE`), and Aero Browser includes it unchanged
except for `manifest.json`, where the Firefox-only `browser_specific_settings` and `background.scripts` keys were
removed so it loads in Chromium.

**Heads up:** since 14 October 2026 YouTube refuses GIF comments sent from desktop, so posting usually fails right
now. The GIF button, search and favorites still work. See https://github.com/rayytor/desktop_gifs/issues/93.
Aero does not try to get around YouTube's block.
